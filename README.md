# 터틀 한글 놀이터

인지·학습 지원이 필요한 학생을 위한 **가상 터틀 자음 관찰 활동**입니다.
학생이 ㄱ~ㅎ 중 글자를 고르고 시작점에 터틀을 놓으면, 터틀이 획순 경로를 따라 움직이며 색칠합니다.
드래그 대신 시작점을 누르거나 큰 ‘시작점에 터틀 놓기’ 버튼을 사용할 수 있습니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd /workspace/Turtle-Robot
npm start
```

기본 포트는 3000입니다. 필요하면 `PORT=3001 npm start`로 변경합니다.
`index.html`, `style.css`, `app.js`, `letters.js`를 정적 호스팅으로도 제공할 수 있습니다.

## GitHub Pages

`.github/workflows/pages.yml`은 `main`에 변경을 푸시하면 정적 웹앱을 GitHub Pages에 배포합니다.
서버 코드, 테스트, SDK 파일은 배포하지 않고 웹앱 파일 4개와 `.nojekyll`만 업로드합니다.

최초 한 번 저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택해야 합니다.
이후 `main` 푸시 또는 **Actions → Deploy Turtle Hangul to GitHub Pages → Run workflow**로 배포합니다.
기본 프로젝트 주소는 `https://taeza81.github.io/Turtle-Robot/`이며 첫 배포 성공 후 사용할 수 있습니다.

## 검증

서버가 실행된 상태에서 Python Playwright와 Chromium이 있는 환경에서는 아래 검증을 실행할 수 있습니다.
이 클라우드에는 두 도구가 기본 제공됩니다. 웹앱 실행 자체에는 필요하지 않습니다.

```sh
python3 tests/browser_check.py
```

14개 자음 자동 재생, 획 사이 무색칠 이동, 재생 중 전체 입력 잠금, 완성 후 잠금 해제,
키보드·모바일 터치, 모션 감소 모드, 태블릿 세로·가로 레이아웃, 로컬 기록 저장·삭제 및 저장 차단 상황을 확인합니다.

## 학습 흐름과 입력 잠금

1. ‘글자 바꾸기’를 눌러 자음 14개 중 하나를 선택합니다.
2. 터틀을 큰 시작점으로 끌거나, 시작점 또는 놓기 버튼을 누릅니다.
3. 터틀이 자동으로 움직이며 각 획을 색칠합니다.
4. 완성한 글자를 관찰합니다. ‘한 번 더 보기’ 또는 ‘다음 글자’로 이어 갑니다.

태블릿 활동 화면은 한 단으로 구성해 중앙 캔버스가 화면 대부분을 차지합니다. 글자 목록은 선택창에,
속도·색상·기록은 교사 설정에 모았습니다. 활동 중 화면에는 현재 글자, 짧은 안내, 큰 터틀 놓기 버튼이 중심이 됩니다.

자동 색칠 시작부터 **글자 전체 완성까지 모든 앱 버튼·입력·설정·SVG 조작을 잠급니다.**
획 사이 이동 때도 해제하지 않습니다. 네이티브 `disabled`, 설정 영역의 `inert`, 포인터 차단 레이어,
캡처 단계의 클릭·실행 키 차단을 함께 적용합니다. 상태 안내는 보조기기로 계속 읽을 수 있습니다.
완료 시 자동 해제됩니다. 브라우저 자체의 새로고침·탭 이동·뒤로 가기는 차단하지 않습니다.
탭이 가려지면 브라우저가 애니메이션을 쉬게 할 수 있으며, 돌아오면 이어서 실행합니다.

속도와 색깔은 시작 전에 바꿀 수 있습니다. ‘움직임 없이 보기’는 터틀을 이동시키지 않고 1.25초마다
획을 하나씩 자동 표시합니다. 이 모드도 완성까지 입력을 잠급니다. 모션 감소 설정이 있는 기기에서는
이 모드로 시작합니다. 자동 이동 중 일시 정지 버튼은 제공하지 않습니다.

## 범위와 검토 사항

- 실제 로봇·USB·BLE·클라우드 계정 없이 동작합니다. 외부 폰트나 CDN 요청이 없습니다.
- 색은 가상 경로를 보여 주며 실제 터틀의 색상 명령 코드와 대응하지 않습니다.
- 다음 획의 시작점까지는 색칠하지 않고 점선으로 가상 이동합니다. 실제 로봇의 연속 라인 주행과 다릅니다.
- `letters.js`의 경로는 필기체를 참고한 교육용 예시입니다. 교사는 수업의 획순·자형 기준을 확인해야 합니다.
  특히 ㅈ·ㅊ 등의 꺾인 획은 인쇄체 모양과 차이가 있습니다.
- 글자별 완료 기록만 브라우저의 `localStorage`에 저장합니다. 숙달도·장애·개인정보는 수집하지 않습니다.
  저장이 차단돼도 놀이할 수 있으며 교사 안내에서 전체 기록을 지울 수 있습니다.
- 안내 듣기는 브라우저·기기의 한국어 음성 지원에 따라 달라집니다.
- 학생 대상 사용성·교육 효과·보조공학 호환성은 실제 수업에서 별도로 검증해야 합니다.

클라우드 온보딩에서 준비한 Python `roboid` SDK는 `/workspace/.venvs/turtle-robot`에 별도로 있습니다.
웹앱은 이 SDK를 요구하지 않으며 실제 로봇 연결은 검증되지 않았습니다.
